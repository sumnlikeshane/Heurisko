# Current capabilities

## Available web path

Exact public npm and local static archive analysis use the shared engine; retained reports, evidence bytes, source conflicts, coverage, downloads and explicit reopen use the shared reader. Memory-only session jobs are not a durable monitor. No target package is installed, imported or executed.

## Separate concurrent S4 lane

The current CLI source has conditional terminal TUI entry and tui REPORT wiring. This web batch documents observed parser behavior and checks noninteractive parity. Visual TUI work and its acceptance are separate; no design is adopted here.

## Remaining product integrations

Genuine heuristics/build/normalized analysis, open-model inference, provenance verification, concrete policy evaluation and monitor/runner remain separate engine dependencies. Request flags do not create those capabilities. PyPI, lockfiles, compare, SARIF, hosted sharing/accounts and optional registry discovery are later scope. No silent closed-model fallback exists.

# Current capabilities

## Available in this browser

The shared producer accepts exact public npm versions and local tar/tar.gz archives. It retains artifact integrity, immutable source candidates, raw differences, evidence bytes, omissions and stage errors. The browser supports explicit review and start, recorded job progress, cancellation requests, report reading, contextual downloads and validated reopening.

Jobs belong to the current reader process. They are not a durable release monitor. No target package is installed, imported or executed. The browser renders the shared report rather than recomputing a verdict.

## Terminal interface

The product CLI opens the keyboard-driven TUI by default when stdin and stdout are terminals. `tui REPORT` opens a retained report; `analyze` and `inspect` remain scriptable commands. The TUI supports local/npm review, real engine progress and cancellation, and retained evidence reading. Local functional checks and the separate TUI visual work do not establish human design acceptance.

Use the [complete CLI reference](../../../docs/CLI%20Reference.md) for exact options. Web workflows use the same engine and report contract; transient browser and terminal UI state are separate.

## Shared integrations still unavailable

The current web workflow has no integrated analysis module, open-model inference, provenance verifier, concrete policy evaluator, rebuild worker or release monitor. Requested AI and policy options record intent; they do not provide those capabilities. No fallback interpretation is synthesized.

Monitoring and meaningful actual open-model work remain complete-product and event obligations. A readable web interface does not close them.

## Later scope

PyPI, lockfile audits, upgrade comparison, SARIF, hosted sharing/accounts and optional registry discovery remain later work. The interface does not expose unsupported registry search or PyPI controls. There is no silent closed-model fallback.

See the [browser guide](browser.md), [identity and limits](concepts-identity.md) or [browser technical reference](../README.md).

# Identity, evidence and limits

## Independent outcomes

Artifact integrity, source association, provenance policy, correspondence, analysis completeness and policy result are separate recorded dimensions. No combined safety score is computed. Local bytes remain local-input; source conflicts stay ambiguous. Empty findings with unavailable analysis are not a clean assessment.

## Observation identity

Report ID describes analysis identity. Full report content digest distinguishes original encoded bytes, including different capture metadata. The opaque observation handle selects an admission into this reader process; it expires on restart. Configuration fingerprint binds recorded tools/options. No navigation changes the immutable report.

## Source and omissions

Full immutable commit, package subtree and build context matter. Candidate ordering, gitHead, tags and names alone are not proof. Excluded/unsupported files, failed stages and missing bytes remain visible in Coverage and Files. Build context does not prove a reproduced build.

## Concrete distribution disposition

The notice package is prepared for review in root `THIRD_PARTY_NOTICES.txt`; the original complete web notices remain unchanged in `apps/web/THIRD_PARTY_NOTICES.txt` and compiled into the delivered JS. It is an inclusion repair, not a release-clearance certificate. The local source-candidate tar is quarantined in ignored scratch and explicitly includes rights-unresolved retained material; do not upload it.

A source checkout downloads third-party tools from their released distributions with scripts disabled/hash checks retained. A binary/image release additionally needs the exact yoga WASM and rpds wheel bundled-object evidence above, the final selected image's bundled installer notice/source-compliance review. Do not infer those from SPDX metadata. Existing base packages retain their shipped copyright/common-license files; redistribution source obligations must be satisfied for the selected image, not waived by retaining a metadata list.

Retrieval receipts preserve the initial 404s, anonymous GitHub API rate-limit 403s and the successful exact-tag/commit retrievals. No credentials were inspected or used to bypass the rate limit. Private reporting activation remains unverified for the same public-lookup restriction; see `SECURITY.md`.

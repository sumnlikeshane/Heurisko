# RAG evaluation data

The shareable corpus in this branch is the curated public setuptools 60.0.0
wheel/source case under [`real/setuptools-60.0.0/`](real/setuptools-60.0.0/).
Its manifest pins archive digests and the source commit; excerpts, questions,
and separate oracle judgments support the M1/M2 probes. The package includes
its MIT license. No package or build instruction is executed by this harness.

Other research downloads and historical comparison artifacts are local-only
and are not part of this branch. Review their source identity, privacy,
licensing, and redistribution terms before publishing them.

Raw logs and exact environment limits are in the [Phase 1 receipt](../../examples/production-phase1/2026-11-01/README.md). The root `pnpm run typecheck` also passes after intake. CI now has an independent offline development-source job. Remote exact-head CI remains unobserved because this change is uncommitted.

An untouched-HEAD `--no-ai` run and a post-intake `--no-ai` run on the same inert local input produced exactly equal outcomes, 16 finding objects and change status/equality sequences. Their report IDs differ because the updated lockfile digest is part of the reviewed module identity; this is an expected new evaluation identity, while historical bytes remain unchanged. After the CLI default repair, a fresh default run matched the post-intake explicit `--no-ai` evaluation ID. This behavior comparison covers one local case; broader AI-off regression remains a Phase 1 gate.
